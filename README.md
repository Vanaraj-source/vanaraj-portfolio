# Vanaraj M — Portfolio

## Preview locally
1. Extract this folder/ZIP.
2. Open `index.html` in a browser. For best local testing, run a static server:
   `python -m http.server 8000`
3. Visit `http://localhost:8000`.

## Deploy free
- Netlify: drag the extracted folder into Netlify's manual deploy area.
- Vercel: import the folder/repository as a static project.
- GitHub Pages: push these files to a repository and enable Pages.

## Before publishing
- Confirm project links and that you are allowed to share them publicly.
- The portfolio currently describes projects from the supplied resume; edit `index.html` if any details need changing.
- The resume PDF is included and linked from the hero.
- This is a static site; the email button opens the visitor's email app and does not submit a backend form.
